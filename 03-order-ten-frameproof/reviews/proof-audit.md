# Proof audit and reproduction

Audited on 10 October 2026 against the completed Lean sources and verification records from 8 October 2026.

The development proves that every binary 10 × 10 separating hash family of type `{1,3}` is a permutation matrix up to independent row complementation. The final declarations in `MainTheorem.lean` are:

```lean
GPT6Astra.every_order_ten_shf_is_trivial
  (A : BinaryMatrix 10) (h : IsSHF A) : IsTrivial A

GPT6Astra.not_openProblem10 : ¬ OpenProblem10
```

`IsSHF` requires a separating row for every designated column and every three other distinct columns. `IsTrivial` requires a bijection assigning one distinguished column to each row, together with the row-complement bits. The theorem has no extra design, row-weight, private-bit, distinct-row, or symmetry assumption.

The source review found no missing case, weakened target, admitted mathematical lemma, or unsafe project definition in the final dependency chain. Normalization derives the four cases `k = 2, 3, 4, 5`; anchoring preserves separation, and a minimum over a finite permutation orbit justifies simultaneous row and column ordering. Each finite case contains exactly 840 separation constraints, 80 row-order constraints, 63 column-order constraints, and 19 fixed-entry constraints. All 1,002 constraints are proved consequences of the canonical matrix hypotheses before their conjunction is refuted. The atom-canonicalization tactic uses Lean's definitional-equality check when changing the hypothesis.

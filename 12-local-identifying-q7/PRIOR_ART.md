# Prior art and claim limits

This package presents a formal exact-value result for local identifying codes in the binary cube Q7. It does not currently certify a historical first result, an open-problem resolution, or priority over earlier literature.

“Local identifying” here requires closed-neighborhood domination and separation of adjacent vertices only, with no exemption for vertices in the code. Ordinary identifying codes separate every distinct pair; locating-dominating variants often impose different endpoint conditions. Comparisons with numerical tables must check the definition before comparing values.

Herva, Laihonen and Lehtilä, “Optimal Local Identifying and Local Locating-dominating Codes,” *Fundamenta Informaticae* 191(3–4), 351–378 (2024), DOI [10.3233/FI-242187](https://doi.org/10.3233/FI-242187), provide the matching definition in Definition 1.3 and report the Q7 interval 21–28 in Table 1. See the [published primary text](https://fi.episciences.org/13881/pdf) and [arXiv record](https://arxiv.org/abs/2302.13351). The definition and table were checked against the primary text. A bounded literature review did not locate an earlier exact-24 result; that negative search is not an exhaustive priority certificate. See the [paper bibliography](paper/q7-local-identifying-draft.bib). Formal verification of the theorem and historical novelty are separate questions.

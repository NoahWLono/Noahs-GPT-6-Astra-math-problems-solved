# Ordinary homogeneous full operator separation

This package proves full operator separation for homogeneous polynomials of degree at least two in at least three variables over an arbitrary characteristic-zero field, assuming the actual gradient quotient is finite-dimensional. It contains the four-page addendum, sixteen Lean proof modules, a literal expanded specification, exact pins and hashes, and independent replay evidence and a successful fresh-output replay of the exact portable publication script.

The final theorem is `NakaiHomogeneousFiniteExpected.expected_finite_gradient_full_operator_separation`. It constructs the displayed endomorphism of the actual hypersurface quotient, identifies its action on every representative, proves every triple commutator with multiplication vanishes, and excludes the unrestricted algebra generated by all multiplications and every actual quotient derivation.

Hessian nonmembership is proved internally by Euler's homogeneous syzygy homotopy, adjugate row identities, homogeneous determinant comparison, and pure powers extracted from a finite quotient. No socle theorem or desired nonmembership conclusion is assumed. `Module.Finite` over the field is the exact finiteness hypothesis. Geometric translations of this condition are not additional formal statements in this package.

The operator and Jacobian-ideal stability retain the prior attributions documented in the paper. Mathematical priority is not established. The weighted-homogeneous case and unrestricted Nakai conjecture are not resolved here. This addendum expands the formal scope of the original fixed-quartic certificate; that certificate and its paper remain unchanged.

The original conditional module is retained byte-for-byte. Its historical comments describe its standalone conditional statement; `NakaiHessianFinite` proves the former nonmembership premise, and `NakaiHomogeneousFinite` assembles the unconditional result under finite gradient quotient.

## Reproduce

Use the exact Lean and mathlib revisions in `pins.json`. The mathlib checkout must have the official cache for the imported modules and dependencies; this script does not download or rebuild a dependency tree. Set three environment variables and run:

```sh
MATHLIB_ROOT=/path/to/pinned/mathlib4 \
LEAN_BINARY=/path/to/pinned/lean/bin/lean \
NAKAI_BUILD_DIR=/path/to/new/empty/output \
bash rebuild.sh
```

The output directory must be empty. The script verifies pins and source bytes, links the existing dependency cache into an output-local overlay, compiles the unchanged EulerIdentity source, and checks all sixteen project modules serially. Each module uses `-j1 -M3072` with 30-second and 3-GiB process-group RSS guards. No existing output is deleted and no previous project object files are used. The original copyright and license of the pinned upstream source remain in that file.

To rebuild the PDF with an existing TeX installation, run `bash paper/build.sh`. It writes local format/configuration support and rendered output beneath `paper/`. PDF timestamps may differ on regeneration; the mathematical TeX source and delivered PDF have separate package hashes.

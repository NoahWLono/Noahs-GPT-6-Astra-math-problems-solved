\section*{Formal mathematical coverage}
The geometric source is a genuine nonsingular Weierstrass curve, with Mathlib's actual point group and function field. The degree $D$ is the sum of actual pole multiplicities, matching the manuscript's convention. Projective values include infinity, constructed through actual residue fields.

\begin{description}[style=nextline]
\item[T1 Global obstruction]
Over algebraically closed constants in arbitrary characteristic, exact translation order $n\ge2$, a nonconstant function and a reduced nonconstant rational update: a global projective recurrence implies update degree $r=1$ and $n\mid D$.
\item[T2 and T3 Finite agreement bounds]
The complete cyclic agreement set has cardinality at most $\min(n,D(r+1))$, including common poles. For a fixed finite menu, the complete union has cardinality at most $\min(n,D\sum_j(r_j+1))$.
\item[T4 Finite field obstruction]
For an odd prime cyclic order and a nonconstant projective recurrence, the function is injective on the cyclic subgroup; the actual PGL element has exact order $n$. The finite-field alternatives and minimal extension-degree divisibility are proved. The function is presented on the ambient group and restricted to that subgroup.
\item[T5 Prime full group obstruction]
For prime $p\ge17$, a nonsingular Weierstrass curve over $\mathbb F_p$ whose full point group has prime cardinality $n\ne p$, and nonzero $G$, every full recurrence of an arbitrary projective-valued function under a base-field PGL element forces that function constant. Hasse, exact point order, generation and representative existence are derived internally.
\item[T6 Deterministic prime cycle]
For any deterministic update and a prime-length closed orbit, nonconstancy within the first $n$ entries implies that those $n$ entries are all distinct. Invertibility is not assumed.
\end{description}
